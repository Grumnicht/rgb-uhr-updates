# RGB-Wanduhr – Home Assistant Updates

Hier liegen die freigegebenen Updates für die Home-Assistant-Steuerung der RGB-Wanduhr.

## Installation

Der RGB-Uhr Update-Manager prüft regelmäßig die Datei `manifest.json`. Neue Versionen werden nur nach Bestätigung über die Home-Assistant-Steuerungsseite installiert. Vor dem Austausch werden die bisherigen Uhr-Dateien lokal gesichert.

**Wichtig:** Es dürfen hier keine privaten Home-Assistant-Dateien, Zugangsdaten, Tokens, WLAN-Passwörter oder Secrets veröffentlicht werden. Änderungen am Wemos/ESPHome gehören nicht in dieses Update-Archiv.

Die Dateien `manifest.json` und `rgb_uhr_update.zip` müssen immer zueinander passen (SHA-256-Prüfsumme). Bei künftigen Updates zuerst das ZIP und danach das Manifest veröffentlichen. Die erste Version `1.0.0` ist der Ausgangsstand.
